# ULTRA AI BRAIN — запуск и бесплатная публикация

Это готовый стартовый проект русскоязычного ИИ-чата. Интерфейс адаптирован для Android и может устанавливаться как PWA.

## Важное ограничение
Проект не обещает бесконечные запросы или доступ ко всем ИИ бесплатно. Бесплатные тарифы имеют квоты, а доступ к моделям меняется. В проекте есть русскоязычный интерфейс, серверная функция Cloudflare Pages, адаптеры Cloudflare Workers AI / Gemini / Groq и ограниченный поисковый запрос DuckDuckGo Instant Answer. Секретные ключи не хранятся в браузере.

## Публикация через Android

1. Открой https://dash.cloudflare.com/ и создай бесплатный аккаунт.
2. Открой https://github.com/ и создай бесплатный аккаунт.
3. В GitHub создай репозиторий `ultra-ai-brain` (можно Public).
4. Загрузи в репозиторий все файлы и папку `functions` из этого архива. Удобнее делать это через браузер GitHub в режиме «Версия для ПК».
5. В Cloudflare Dashboard открой **Workers & Pages → Create → Pages → Connect to Git**.
6. Подключи GitHub и выбери `ultra-ai-brain`.
7. Framework preset: **None**. Build command оставь пустым. Build output directory: `public`.
8. Нажми **Save and Deploy**. Cloudflare выдаст адрес вида `https://имя.pages.dev`.

## Подключение бесплатных моделей (режим нескольких ИИ)

В проект добавлены три адаптера: Cloudflare Workers AI, Google Gemini API и Groq. Можно использовать один или несколько одновременно. Если подключено несколько, ответы запрашиваются параллельно и затем объединяются. Бесплатные тарифы и доступные модели зависят от страны, аккаунта и текущих условий провайдера.

- Cloudflare: binding `AI` (Workers AI).
- Gemini: создай API-ключ в Google AI Studio и добавь в Cloudflare Pages → Settings → Variables and Secrets секрет `GEMINI_API_KEY`. По умолчанию модель `gemini-2.5-flash`; если она недоступна, задай `GEMINI_MODEL`.
- Groq: создай API-ключ в GroqCloud и добавь секрет `GROQ_API_KEY`. По умолчанию модель `llama-3.3-70b-versatile`; если недоступна, задай `GROQ_MODEL`.

Добавляй ключи только как серверные Secrets в Cloudflare, никогда в HTML или публичный GitHub.

## Подключение Cloudflare Workers AI

1. Открой Cloudflare Dashboard → **Workers & Pages → твой Pages-проект → Settings → Bindings → Add → Workers AI**.
2. Имя переменной укажи строго `AI`.
3. Сохрани binding и сделай новый deployment. Официальная инструкция: https://developers.cloudflare.com/pages/functions/bindings/.
4. По умолчанию используется `@cf/meta/llama-3.1-8b-instruct`. Если модель недоступна, задай `AI_MODEL` с ID доступной модели из каталога Workers AI.

## Установка на Android

1. Открой опубликованный `https://...pages.dev` в Chrome.
2. Нажми меню ⋮.
3. Выбери **Установить приложение** или **Добавить на главный экран**.
4. Значок ULTRA AI появится среди приложений.

## Локальный запуск (необязательно)

Нужен компьютер с Node.js:
```bash
npm install
npx wrangler pages dev public
```
Открой адрес, который покажет Wrangler.

## Что уже работает / что нужно улучшить

- Готов адаптивный интерфейс чата.
- Готов серверный endpoint `/api/chat`.
- Реализованы вызовы нескольких провайдеров и объединение результатов, если подключены несколько.
- Поиск DuckDuckGo Instant Answer может возвращать краткие ответы, а не полноценную выдачу ссылок; это не полноценный поисковый движок.
- Режим нескольких ИИ работает только если настроены как минимум два провайдера; бесплатные квоты могут закончиться или модели могут стать недоступны.
- История диалогов, загрузка файлов, голос и изображения пока не реализованы.

Внимание: бесплатный тариф Gemini ограничен и может использовать переданные запросы для улучшения продуктов Google. Не отправляй личные/секретные данные. См. https://ai.google.dev/gemini-api/docs/pricing.
